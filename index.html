AgentOS P1 · 真实链路

一句话任务 → LLM 规划 → 只读库 → 自动报告 → 人工审批 → 多通道投递（失败自动回退）｜更新：2026-11-12

它解决什么

  • 可中断：高风险动作 interrupt() 等人工 approve/reject
  • 可恢复：SQLite checkpoint，进程重启后继续，不重跑已完成步骤
  • 只读安全：mode=ro + query_only，固定 SQL 参数化，无写库工具
  • 零丢件：投递 Telegram → 本地 IM → 收件箱，失败自动回退并审计
